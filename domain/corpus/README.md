# Regulatory Corpus — /domain/corpus/

This directory holds the curated Indian regulatory text used by the BM25 corpus index.

## Planned contents
- PMLA 2002 (as amended) — relevant sections
- RBI Master Direction on KYC — current version
- FIU-IND Reporting Format Guide v2.2
- FIU-IND red-flag indicator typology reports
- FATF Recommendations (selected, relevant to Indian context)
- FINnet / FINGate 2.0 reporting format PDF excerpts

## Status
NOT YET POPULATED — Phase 3 task.

## Sourcing rule
All documents in this directory must be from primary or officially published sources.
Each file must include a `source:` header with the URL and date accessed.
Do NOT ingest secondary or paraphrased sources into the corpus — an incorrect source corrupts all downstream citations.
